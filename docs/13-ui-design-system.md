# 13 UI DESIGN SYSTEM

## Technologies
- **CSS Framework**: TailwindCSS
- **Icons**: Lucide React

## Color Palette
- **Backgrounds**: Slate-50, Slate-100
- **Primary Actions**: Blue-600 (Hover: Blue-700)
- **Text**: Slate-900 (Headings), Slate-500/600 (Body text)

## Typography
Default system sans-serif fonts are used for a clean, modern aesthetic.
