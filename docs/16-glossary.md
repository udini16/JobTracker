# 16 GLOSSARY

- **Hermes**: Refers to the open-source LLM model (Nous Hermes) used to generate the emails, or more broadly, the AI persona of this system.
- **Puppeteer**: A Node library for automating headless Chromium browsers, used here for web scraping.
- **Nodemailer**: A Node.js module used to dispatch emails via Gmail SMTP.
- **Tracking Pixel**: A 1x1 transparent image embedded in emails to track open rates.
