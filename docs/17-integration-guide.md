# 17 INTEGRATION GUIDE

## External Systems
1. **OpenAI / OpenRouter API**: Used for AI generation. Replace the Base URL in `.env` if using a custom provider like Together AI.
2. **Telegram Bot API**: Requires talking to `@BotFather` on Telegram to create a bot and get a token. Use `@userinfobot` to get your Chat ID.
3. **Nodemailer (Gmail)**: Uses Gmail App Passwords to send emails directly from your personal account.
