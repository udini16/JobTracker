# Documentation Update Rule

You MUST ALWAYS update the relevant markdown files in the `docs/` folder whenever you implement new features, make significant updates, or change the architecture of the project.

## Requirements:
1. After completing any code changes for a new feature or update, before concluding your task, review the `docs/` folder.
2. Specifically check `docs/project-status.md` and any relevant walkthrough or architecture files (e.g., `docs/21-walkthrough.md`).
3. Update these files to accurately reflect the newly implemented functionality.
4. Ensure the documentation remains consistent, clear, and up-to-date with the current state of the codebase.
